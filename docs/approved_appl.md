## Формулировка темы проекта

Разработка детерминированного симулятора игровой логики osu!stable и собственного программного 2D-растеризатора для визуализации реплеев

## Используемые технологии

- Rust + Cargo
- Собственные парсеры текстового формата карт .osu и бинарного формата реплеев .osr, включая декодирование ULEB128
- Вычислительная геометрия (кривые Безье и дуги окружностей)
- Конечные автоматы и событийная модель игровой логики
- Собственный CPU-растеризатор с кадровым буфером
- minifb для вывода изображения в окно
- Экспорт кадров и видеоряда в PPM/Y4M
- CLI

> [!IMPORTANT] Готовые игровые движки и графические API для реализации растеризации не используются.

## Ожидаемый результат

- Библиотека и CLI-утилита на Rust для разбора файлов .osu и .osr и воспроизведения реплеев osu!stable в режиме standard. 
- Реализация включает собственную игровую логику, вычисление геометрии объектов и CPU-растеризатор с кадровым буфером. 
- Предусмотрены просмотр реплея в окне, экспорт кадров в PPM/Y4M и автоматизированные тесты основных алгоритмов.
